# The public site: `frontends/web`

The Piloti landing page, blog and changelog: an Astro service, German and
English, with Keystatic as the CMS the platform owner writes in. Deployed as
its own container; it shares nothing with the product UI but the brand.

npm, not bun. The Astro toolchain ships its own lockfile and bundler, and this
is the one Node tree here that bun does not install.

## Obligations

| When you | You must | What fails you |
|---|---|---|
| Add a page or string | Provide both `de` and `en` | A visitor gets a 404 in their language |
| Touch the changelog | Edit the reno note, never `src/data/changelog.json` | That file is generated by `scripts/release_notes.py publish` on merge to `develop`, and your edit is overwritten |
| Add a draft post | Leave it a draft; `PUBLIC_INCLUDE_DRAFTS` is preview-only | `astro build` bakes the result into the image, so a release build with drafts on publishes every unfinished post |
| Change the content schema | Update `keystatic.config.ts` with it | The CMS writes content the site cannot render, and only the platform owner sees it |

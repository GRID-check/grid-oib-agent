## Claude Code specifics

Scoped guides live beside the code they govern, as `AGENTS.md` with a
`CLAUDE.md` bridge next to it. Claude loads a nested `CLAUDE.md` only *after*
it reads a file in that directory, so the guide arrives one step late and never
at all for a question answered without opening a file. When you start work in
one area, read that area's `AGENTS.md` first. Why, and what belongs in which:
[`AGENTS.md`](AGENTS.md#where-the-scoped-guides-are).

`.claude/` is generated by `task agents:setup` and gitignored. Never commit into
it, and never put a rule in `.claude/rules/` expecting it to survive.

## Claude Code specifics

Scoped guides live beside the code they govern, as `AGENTS.md` with a
`CLAUDE.md` bridge next to it. Claude loads a nested `CLAUDE.md` only *after*
it reads a file in that directory, so the guide arrives one step late and never
at all for a question answered without opening a file. When you start work in
one area, read that area's `AGENTS.md` first. Why, and what belongs in which:
[`AGENTS.md`](AGENTS.md#where-the-scoped-guides-are).

`.claude/` is generated by `task agents:setup` and gitignored, with three
committed exceptions: `settings.json` and the two hooks it registers under
`.claude/hooks/`, which run the preflight before Claude edits anything.
Claude Code reads hooks from there and nowhere else, so that file has to be
source. Everything else in `.claude/` is apm's output: nothing you add survives,
and a rule in `.claude/rules/` least of all.
[`docs/contributing/agent-preflight.md`](docs/contributing/agent-preflight.md).
